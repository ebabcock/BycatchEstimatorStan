# getIC Function to extract WAIC and LOOIC from fitted stan model object

getIC Function to extract WAIC and LOOIC from fitted stan model object

## Usage

``` r
getIC(mod1, useCode)
```

## Arguments

- mod1:

  rstan or cmndstanr object

- useCode:

  value "cmdstanr" or "rstan" to indicate code used in fit
