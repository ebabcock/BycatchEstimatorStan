# plotMortalityFunc Function to plot both bycatch and bycatch mortality

plotMortalityFunc Function to plot both bycatch and bycatch mortality

## Usage

``` r
plotMortalityFunc(modelyrSum1, Species)
```

## Arguments

- modelyrSum1:

  Dataframe with data to plot

- Species:

  Common name of species

## Value

Prints out a ggplot
